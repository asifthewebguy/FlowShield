# FlowShield - Release v1.1.6

## 🚀 New Features

### 🔐 Enhanced Authentication
- **Remember Email**: The desktop application now remembers your email address, so you don't have to re-type it every time you log in.
- **Auto Login (Remember Me)**: Added a "Remember me for 30 days" option. When selected, your session will stay active for 30 days instead of the standard 1 hour.

## 🛠️ Improvements
- **Desktop App**: Updated `LoginForm` UI with a new "Remember me" checkbox.
- **Security**: Server-side token generation now supports variable expiry times based on user preference.
