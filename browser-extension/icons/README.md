# Icons

Generate PNG icons from `icon.svg` at the required sizes:

```bash
# Using Inkscape (or any SVG→PNG tool):
inkscape icon.svg -w 16  -h 16  -o icon16.png
inkscape icon.svg -w 48  -h 48  -o icon48.png
inkscape icon.svg -w 128 -h 128 -o icon128.png
```

Or use an online tool like https://svgtopng.com — upload `icon.svg`, export at 16, 48, and 128 px.
